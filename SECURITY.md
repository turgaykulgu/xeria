# Security Policy

## Official Download

The official XERIA Windows installer is available here:

https://xeriasoft.com/downloads/XERIA-setup.exe

Do not download XERIA from unofficial mirrors, third-party file-sharing websites, or repackaged installer sources.

## Code Signing

The XERIA Windows installer is digitally signed.

Before installing, users should verify that the installer is downloaded from the official XERIA website and that the Windows publisher information matches the official publisher identity.

## Product Purpose

XERIA is a legitimate Windows desktop application for secure PDF watermarking, personalized batch PDF generation, PDF encryption, trace-code watermarking, optional QR traceability, and controlled document distribution.

XERIA does not include bundled adware, browser extensions, cryptocurrency miners, unwanted background payloads, or third-party installers.

## Security Reports

If you believe you have found a security issue related to XERIA, please contact:

[support@xeriasoft.com](mailto:support@xeriasoft.com)

Please include:

* A clear description of the issue
* Steps to reproduce the issue
* The XERIA version number
* Your Windows version
* Relevant screenshots or logs, if available

## False Positive Reports

If Microsoft Defender, Microsoft SmartScreen, or another security product incorrectly flags the official XERIA installer, please report the issue to:

[support@xeriasoft.com](mailto:support@xeriasoft.com)

Please include:

* The exact warning message
* The XERIA installer file name
* The download URL used
* The security product name and version
* A screenshot of the warning, if available

## Supported Versions

Only the latest publicly available version of XERIA is actively supported.

Users are encouraged to download updates only from the official XERIA website:

https://xeriasoft.com
