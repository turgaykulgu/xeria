# XERIA 2.0.1 Release Notes

Direct installer released: November 9, 2026.
Microsoft Store: version 2.0.1 submission successfully processed (notification received by November 10, 2026). Store rollout may take time to become visible to all customers.

## English

### Improved usability
- Added an OCR shortcut to the home screen for quicker access to text recognition and export tools.
- Refined PDF Editor usability and general interface consistency.
- Applied minor bug fixes and reliability improvements.

### Distribution
- Direct installer 2.0.1: https://xeriasoft.com/downloads/XERIA-setup.exe
- Microsoft Store 2.0.1: https://apps.microsoft.com/detail/9P37ZD7SQNZP (submission successfully processed; rollout may take time).

The multilingual OCR engine and drag-and-drop PDF Editor enhancements were introduced in XERIA 2.0.0 and remain available in 2.0.1.
