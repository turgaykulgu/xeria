# XERIA 2.0.1 Release Notes

Direct installer released: November 9, 2026.
Microsoft Store: version 2.0.1 submitted for certification on November 9, 2026; version 2.0.0 remains available until approval and publication.

## English

### Improved usability
- Added an OCR shortcut to the home screen for quicker access to text recognition and export tools.
- Refined PDF Editor usability and general interface consistency.
- Applied minor bug fixes and reliability improvements.

### Distribution
- Direct installer 2.0.1: https://xeriasoft.com/downloads/XERIA-setup.exe
- Microsoft Store: https://apps.microsoft.com/detail/9P37ZD7SQNZP (2.0.1 pending certification).

The multilingual OCR engine and drag-and-drop PDF Editor enhancements were introduced in XERIA 2.0.0 and remain available in 2.0.1.

## Türkçe

### Kullanılabilirlik iyileştirmeleri
- Metin tanıma ve dışa aktarma araçlarına daha hızlı erişim için ana ekrana OCR kısayolu eklendi.
- PDF Düzenleyici kullanım kolaylığı ve genel arayüz tutarlılığı iyileştirildi.
- Küçük hatalar giderildi ve güvenilirlik iyileştirmeleri yapıldı.

### Dağıtım
- Doğrudan kurulum dosyası 2.0.1: https://xeriasoft.com/downloads/XERIA-setup.exe
- Microsoft Store: https://apps.microsoft.com/detail/9P37ZD7SQNZP (2.0.1 sertifikasyon aşamasında).

Çok dilli OCR ve sürükle-bırak PDF Düzenleyici geliştirmeleri 2.0.0 sürümünde sunuldu ve 2.0.1'de kullanılmaya devam ediyor.
