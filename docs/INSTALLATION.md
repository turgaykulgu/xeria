# Installation Guide

This guide explains how to download and install XERIA safely on Windows.

## Recommended Installation Method: Microsoft Store

https://apps.microsoft.com/detail/9P37ZD7SQNZP

Current Microsoft Store version:

**XERIA 1.9.4**

Microsoft Store is recommended for most users because it provides a smoother Windows installation experience and Store-managed updates.

## Alternative Installation Method: Direct Installer

https://xeriasoft.com/downloads/XERIA-setup.exe

Current direct installer version:

**XERIA 1.9.4**

The direct installer remains available as an official alternative installation method.

Microsoft Store and direct installer distribution channels are aligned on the same public version.

Do not download XERIA from unofficial mirrors, third-party file-sharing websites, repackaged installers, or unknown download sources.

## System Requirements

Recommended environment:

* Windows 10 or Windows 11
* 64-bit Windows system
* Minimum supported resolution: **1024 × 768**
* Recommended resolution: **1366 × 768 or higher**
* Recommended Windows display scaling: **100% to 175%**
* Internet access for initial license activation, periodic validation, updates, cloud integrations, and email integrations

For detailed display behavior and tested configurations, see [Display Requirements](../DISPLAY-REQUIREMENTS.md).

## Installation Steps

### Option 1 — Install from Microsoft Store

1. Open https://apps.microsoft.com/detail/9P37ZD7SQNZP
2. Select **Get** or **Install**.
3. Follow the Microsoft Store installation flow.
4. Launch XERIA from the Start Menu.
5. Start with the built-in workflow wizard or open the required PDF workflow directly.

### Option 2 — Install with the Direct Installer

1. Download https://xeriasoft.com/downloads/XERIA-setup.exe
2. Run the installer.
3. Follow the installation steps shown by Windows.
4. Launch XERIA from the Start Menu or desktop shortcut.
5. Start with the built-in workflow wizard or open the required PDF workflow directly.

## Display Scaling and Multi-Monitor Use

XERIA 1.9.1 introduced adaptive scaling for high-DPI settings and different screen resolutions. XERIA 1.9.4 further improves workspace behavior on 4K and other large displays.

The application can switch to compact navigation on smaller displays, fit large secondary windows within the usable work area, recalculate its layout when moved between monitors with different DPI settings, and make better use of available workspace when maximized or restored on large high-resolution monitors.

For the best result after changing Windows display scaling, close and reopen XERIA after applying the new Windows setting.

## Before Installing the Direct Installer

Verify that:

* The installer was downloaded only from the official XERIA website
* The installer came from https://xeriasoft.com/downloads/XERIA-setup.exe
* The Windows publisher information matches the official publisher identity
* The installer has not been obtained from an unofficial mirror or modified source
* The installer is digitally signed

## Trial and License Activation

XERIA includes an unlimited free trial.

Trial limitations include:

* Email sending is disabled
* Generated PDFs include a visible trial banner
* A valid license is required to remove trial banners and enable licensed functionality

License activation requires an internet connection.

Since XERIA 1.9.0, license synchronization supports license changes more reliably and the latest verified license status is stored securely on the local device for offline use.

An internet connection may still be required for periodic validation, license changes, updates, and online services.

## Security and Code Signing

The recommended installation source is Microsoft Store.

The XERIA direct installer is digitally signed and is available only from the official XERIA website.

XERIA does not include bundled adware, browser extensions, cryptocurrency miners, unwanted background payloads, or third-party installers.

## Microsoft Defender or SmartScreen Notices

Newly released direct-installer builds may occasionally trigger reputation-based warnings.

If a warning appears:

* Verify that the installer came from https://xeriasoft.com/downloads/XERIA-setup.exe
* Verify the digital signature and publisher information
* Do not use an unofficial mirror
* You may use the Microsoft Store version instead

For suspected false positives, contact [support@xeriasoft.com](mailto:support@xeriasoft.com).
