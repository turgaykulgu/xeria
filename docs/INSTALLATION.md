# Installation Guide

This guide explains how to download and install XERIA safely on Windows.

## Official Download

The official XERIA installer should only be downloaded from the official XERIA website:

https://xeriasoft.com/downloads/XERIA-setup.exe

Do not download XERIA from unofficial mirrors, third-party file-sharing websites, repackaged installers, or unknown download sources.

## System Requirements

XERIA is a Windows desktop application.

Recommended environment:

* Windows 10 or Windows 11
* A standard Windows user account with permission to install desktop applications
* Internet access for license activation, trial validation, updates, and cloud/email integrations
* A PDF workflow where secure watermarking, encryption, trace-code watermarking, or personalized batch processing is required

## Before Installing

Before running the installer, please verify:

* The installer was downloaded from the official XERIA website
* The installer file name matches the version provided on the official download page
* The Windows publisher information is displayed as the official publisher identity
* The installer has not been downloaded from an unofficial mirror or modified source

## Installation Steps

1. Visit the official XERIA download page:

   https://xeriasoft.com/dl

2. Download the latest XERIA installer.

3. Run the installer.

4. Follow the installation steps shown by Windows.

5. After installation, launch XERIA from the Start Menu or desktop shortcut.

6. Start with the built-in workflow wizard or open the relevant PDF processing page directly.

## Trial and License Activation

XERIA may be used in trial mode where available.

For Pro features, a valid license is required.

License activation requires an internet connection. After activation, XERIA validates the license through the official XERIA licensing system.

For license, purchase, activation, or trial questions, please contact:

[support@xeriasoft.com](mailto:support@xeriasoft.com)

## Security and Code Signing

The XERIA Windows installer is digitally signed.

Users should always download the installer from the official XERIA website and verify the Windows publisher information before installing.

XERIA is a legitimate Windows desktop application for secure PDF watermarking, personalized batch PDF generation, PDF encryption, trace-code watermarking, optional QR traceability, and controlled document distribution.

XERIA does not include bundled adware, browser extensions, cryptocurrency miners, unwanted background payloads, or third-party installers.

## Microsoft Defender or SmartScreen Notices

Microsoft Defender, Microsoft SmartScreen, or another security product may sometimes show a warning for newly released or recently updated desktop software, especially when a new installer file has not yet built enough reputation.

If you receive a warning while downloading or installing the official XERIA installer, please verify that:

* You downloaded the installer only from https://xeriasoft.com/dl
* The installer is digitally signed
* The publisher information matches the official publisher identity
* The file was not obtained from an unofficial mirror or third-party website

If you believe the warning is incorrect, please contact:

[support@xeriasoft.com](mailto:support@xeriasoft.com)

Please include:

* The exact warning message
* The installer file name
* The download URL used
* Your Windows version
* The security product name
* A screenshot of the warning, if available
